Cara Build & Menjalankan
1. Compile aplikasi React menjadi file statis (client/dist):
	npm run build
2. Jalankan satu proses server Express:
	npm start
3. Akses aplikasi:
​	- Dari komputer lokal: http://localhost:4000
​	- Dari perangkat lain di jaringan LAN: http://<IP-LOKAL-KOMPUTER>:4000 (cukup buka port 4000 pada Firewall)
